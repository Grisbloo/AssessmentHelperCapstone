## 1. Personas


### Faculty Member(Evaluated)

**Goals:**

- See and get noticed when their evaluation due date is coming up
- Search for potential observers
- Coordinate a date for the evaluation to occur
- Coordinate what standards they are going to be evaluated on
- View the submitted evaluation report
- Sign off on the submitted evaluation report



## 2. User Stories


### Faculty Member(Evaluated)

- As a faculty member, I want to see when I am due for an evaluation so I can prepare. I may want to be notified through a notification.

- As a faculty member, I want to be able to a list of up to five potential observers that match the criteria for the subject that I am being evaluated on.
