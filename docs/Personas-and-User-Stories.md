## 1. Personas


### Faculty Member(Evaluated)

**Goals:**

- See and get noticed when their evaluation due date is coming up
- Search for potential observers
- Coordinate a date for the evaluation to occur
- Coordinate what standards they are going to be evaluated on
- View the submitted evaluation report
- Sign off on the submitted evaluation report



## 2. User Stories


### Faculty Member(Evaluated)

- As a faculty member, I want to see when I am due for an evaluation so I can prepare. I may want to be notified through a notification.

- As a faculty member, I want to be able to a list of up to five potential observers that match the criteria for the subject that I am being evaluated on. 

- As a faculty member, I want to coordinate a date for my evaluation so I can make sure the observation works with my schedule.

- As a faculty member, I want to view the available evaluation dates so I can choose a time that works for me.

- As a faculty member, I want to coordinate with my observer before the evaluation so we can agree on the date and time.

- As a faculty member, I want to know which standards I will be evaluated on so I can understand what will be assessed.

- As a faculty member, I want to view the evaluation standards before my observation so I can prepare for the evaluation.

- As a faculty member, I want to view the status of my evaluation so I know whether it is pending, scheduled, or completed.

- As a faculty member, I want to view my submitted evaluation report so I can review the results.

- As a faculty member, I want to sign off on my submitted evaluation report so I can acknowledge that I have reviewed it.

- As a faculty member, I want to receive a notification when my evaluation has been scheduled so I know when it will occur.

- As a faculty member, I want to receive a notification when my evaluation report is available so I can review it.

- As a faculty member, I want to see information about my selected observer so I know who will be conducting my evaluation.

- As a faculty member, I want to see my evaluation history so I can review previous evaluations.
